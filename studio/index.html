Studio virtuel RTV BREK

Deux habillages aux couleurs de RTV BREK — La voix de la Révolution Classique : l’écran d’attente « Votre émission commence dans quelques instants », et l’habillage du direct (logo, EN DIRECT, heure d’Haïti en temps réel, bandeau de l’invité, défilant « ACTUALITÉ » alimenté par les titres du site). Ils s’ajoutent par-dessus votre caméra dans le logiciel gratuit OBS Studio.

3. Habillage du direct

L’aperçu montre l’affiche en fond ; dans OBS, le fond est transparent et c’est votre caméra qui apparaît derrière.

Globe animé (générique)

Le globe tourne, s’arrête sur Haïti, relie Haïti à sa diaspora, puis affiche le titre RTV BREK. À utiliser en ouverture d’émission, avant l’écran d’attente.

Dans OBS : source Navigateur, 1920 × 1080. Ajoutez &mode=boucle au lien pour un globe qui tourne en continu (fond d’écran de plateau), et &fond=0 pour un fond transparent.

4. Installer dans OBS Studio (une seule fois)

  1. Installez OBS Studio (gratuit) depuis obsproject.com.
  2. Créez une scène « Attente » : + sous « Sources » → Navigateur → collez le lien de l’écran d’attente, largeur 1920, hauteur 1080.
  3. Créez une scène « Plateau » : ajoutez d’abord Périphérique de capture vidéo (votre webcam ou votre téléphone), puis par-dessus une source Navigateur avec le lien de l’habillage, 1920 × 1080.
  4. Dans OBS : Paramètres → Stream → Service YouTube → Connecter le compte (compte RTV BREK). Puis Paramètres → Sortie : 2 500 kb/s, et Vidéo : 1280 × 720, 30 i/s.
  5. Le jour J : affichez la scène « Attente », cliquez Démarrer le streaming, puis passez sur « Plateau » quand vous commencez.

5. Pendant le direct

Dans OBS, clic droit sur la source de l’habillage → Interagir, puis :

  • E : mode édition — cliquez sur le nom, la fonction ou le titre pour les changer en direct (Échap pour valider).
  • L : afficher ou masquer le bandeau du nom.
  • T : afficher ou masquer le défilant.
  • D : basculer entre EN DIRECT et REPLAY.

Le défilant affiche automatiquement les derniers titres publiés sur le site.

Votre téléphone comme caméra

Installez DroidCam sur le téléphone Android et sur l’ordinateur (même Wi-Fi) : le téléphone apparaît dans OBS comme une webcam.
